#  AWS Nginx Web Server Portfolio
My first hands-on DevOps and Cloud deployment project showcasing a live professional portfolio hosted on an AWS EC2 instance.
---
### 🌐 Live Demo
You can view the live deployment here: **[http://3.94.106.232](http://3.94.106.232)**
---
###  Tech Stack & Tools
* **Cloud Provider:** AWS EC2 (Ubuntu `t2.micro`)
* **Web Server:** Nginx
* **OS & Tools:** Linux Administration, Nano, SSH, Git & GitHub
* **Frontend:** HTML5, CSS3 (Custom Dark Mode Theme)
---
### 📂 Project Overview
Successfully configured AWS Security Groups (HTTP Port 80 & SSH Port 22), managed remote Linux file permissions, deployed Nginx via systemd, and hosted a custom responsive landing page from scratch.
